# TopDps

TopDps — аддон-помощник по приоритетам способностей и боевой панели для World of Warcraft 3.3.5a.

Текущая версия: **2.1.0**

## Поддерживаемые специализации

Ротация и боевая панель:

- Рыцарь смерти — Кровь, Лед, Нечестивость;
- Друид — Баланс, Сила зверя (ротация работает в форме кошки);
- Охотник — Повелитель зверей, Стрельба, Выживание;
- Маг — Тайная магия, Огонь, Лед;
- Паладин — Воздаяние;
- Жрец — Тьма;
- Разбойник — Ликвидация, Бой, Скрытность;
- Шаман — Стихии, Совершенствование;
- Чернокнижник — Колдовство, Демонология, Разрушение;
- Воин — Оружие, Неистовство.

Только боевая панель:

- Друид — Исцеление;
- Паладин — Свет, Защита;
- Жрец — Послушание, Свет;
- Шаман — Исцеление;
- Воин — Защита.

Для ветки «Сила зверя» ротация намеренно отключается вне формы кошки, поэтому медведь получает панель без DPS-рекомендаций.

## Ротация

- Выбирает следующую рекомендуемую способность из фактически изученных заклинаний и не зависит от наличия кнопки на видимой action bar.
- При наличии подходящей кнопки подсвечивает её на стандартных панелях Blizzard.
- Два варианта подсветки: Blizzard и Cheese.
- Для модификаторов следующей автоатаки поддерживается отдельный next-swing канал с независимой подсветкой.
- Опциональные центральные иконки основной рекомендации продолжают работать, даже если способности нет на action bar.
- Настройка размера и прозрачности центральных иконок.
- Настройка опережения подсветки по окончанию отката от `0` до `0.75` секунды.
- Отдельное включение и выключение категорий способностей для поддерживаемой специализации.
- Для специализаций, где это требуется, поддерживаются movement-aware приоритеты и упреждающее обновление DoT/эффектов с учётом времени каста.

## Экспериментальные функции

Экспериментальные функции требуют двойного opt-in: сначала общего разрешения в настройках, затем отдельного включения функции для конкретной специализации. По умолчанию они выключены.

Сейчас доступна экспериментальная оценка time-to-die, которую Demonology и Destruction Warlock могут использовать при автоматическом выборе проклятия. При недостаточных данных ротация сохраняет обычный стабильный fallback.

## Боевая панель

Панель работает независимо от ротации и предназначена для отображения состояний, которые неудобно включать в последовательность рекомендаций.

Поддерживаются группы:

- обязательные собственные бафы — обычно скрыты и появляются при отсутствии;
- вариативные состояния — текущие формы, стойки, печати, аспекты и аналогичные переключаемые бафы;
- проки — показываются только во время действия с таймером;
- защита и утилити — готовность и время восстановления способностей;
- трини и дополнительные кулдауны — трини, дополнительные активные эффекты и другие отслеживаемые способности.

Для проков доступны общий переключатель звуковых уведомлений и индивидуальные настройки звука. Элементы и группы панели можно настраивать отдельно для специализации. По умолчанию DPS-профили сфокусированы на обязательных состояниях, основных атакующих кулдаунах, ресурсах и полезных для ротации проках; ситуативную защиту и утилити можно включить вручную.

Видимость панели настраивается отдельно для открытого мира и PvE-инстансов. Эквивалентные рейдовые бафы и дебафы учитываются централизованно, чтобы панель не требовала уже заменённый полноценным аналогом эффект.

## Управление

- Ротация и боевая панель включаются независимо для каждого персонажа.
- Общий режим работы применяется к обеим функциям: везде, подземелья и рейды, только рейды или полностью выключено.
- Панель можно перемещать и настраивать по размеру, прозрачности и отображению вне боя.
- Перемещаемая кнопка у миникарты даёт быстрый доступ к основным переключателям.
- Русская и английская локализация интерфейса.
- Страница отладки с выводом рекомендаций и журналом аддона.

## Установка

1. Скачайте архив нужного релиза.
2. Распакуйте папку `TopDps` в:
   `World of Warcraft/Interface/AddOns/`
3. Перезапустите игру или выполните `/reload`.

Итоговый путь должен выглядеть так:

```text
World of Warcraft/Interface/AddOns/TopDps/TopDps.toc
```

## Команды

- `/topdps` — открыть настройки аддона.
- `/td` — короткий вариант команды.

## Совместимость и обновление до 2.1.0

TopDps предназначен для WoW **3.3.5a**. Подсветка action bar рассчитана на стандартные панели Blizzard, но сама центральная рекомендация больше не зависит от наличия способности на видимой панели.

Версия **2.1.0** использует SavedVariables schema **5**. При обновлении с **2.0.0** (schema 4) `TopDpsDB` создаётся заново, поэтому глобальные, per-spec и настройки панели нужно проверить повторно. `TopDpsCharDB` хранится отдельно и сохраняет per-character переключатели ротации и панели.

SavedVariables версий 1.x также не мигрируются. Старый `RpalTopDpsDB` больше не используется.

После обновления до 2.1.0 рекомендуется один раз открыть настройки и проверить общий режим, ротацию, видимость и состав боевой панели.
